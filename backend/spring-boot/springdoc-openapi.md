Documenting the REST API is essential for making them understandable and usable by other developers. springdoc-openapi is a java library that automatically generates API documentation for Spring boot REST APIs. It follows the OPEN API (swagger) standard.

# WHY DOCUMENT REST APIs?
1. Helps developers understand available endpoints and their request/response formats.
2. Reduces dependencies on manual explanations.
3. Improves API onboarding
4. Makes integration with other system easier.

Why there was a need of useMemo and useCallback hook when we have memo in js?
                            OR
What is the issue with memo in react?

Ans - In react, everything is created on every render (including objects and functions).

In JavaScript, two objects or functions that look the same are actually different.( Different refrences).
Therefore, if objects or functions are passed as props, the child components will always see them as new props.
Hence, if props are different btw re-renders, memo will notwork.

So, we need to memoise the objects and functions, to make them stable.
HENCE, useMemo and useCallback hooks were introduced.


UseMemo hook -> used to memoise the values,
Values passed into the hook is stored in memory and returned in subsequent re-renders, as long as dependencies stay the same.

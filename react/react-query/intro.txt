- Powerful library for managing remote (server) state.
- Many features that allows us to write a lot less code, while also making the UX a lot better
- Data is stored in cache.
- Automatic loading and error state 
- Automatic re-fetching to keep state synched.
- Pre-fetching 
- Easy remote state mutation
- Offline support

- Needed because remote state is fundamentally different from regular UI state.
